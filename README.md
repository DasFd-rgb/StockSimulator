# StockGame V3

C 언어로 작성한 Windows 콘솔 주식 모의투자 프로그램입니다. 초기 현금 1,000만원과 가상 회사 30개로 시작합니다. 공포지수와 기업 재무·업종·난수가 가격에 영향을 줍니다.

## 실행

GitHub Releases에서 실행 파일이 포함된 압축을 내려받아 전체를 풀어 주세요.

| 용도 | 실행 | 가격 갱신 |
|---|---|---|
| 일반 사용자용 | `production/run.cmd` | 10초 |
| 시연용 | `presentation/run.cmd` | 3초 |

소스 ZIP에는 빌드 결과가 포함되지 않습니다. Visual Studio에서는 `StockSimulatorV2.sln`을 열거나 루트의 `build.cmd`를 실행합니다. 기존 프로젝트 경로와 솔루션 이름을 재사용하며 화면과 배포 버전은 V3입니다. 현재 프로젝트 도구 집합은 v143입니다. Visual Studio 2019 사용 시 설치된 v142로 선택을 바꿔야 합니다.

## V3 변경 보고

일반용 갱신을 30초에서 10초로 줄였습니다. 실행 인수를 제거하고 main(void)로 시작합니다. 보유 종목 폐지 시 회사명·ID·수량·손실 알림을 보여 주며 `ack` 전까지 저장합니다. 상세는 최근 30건, 전체 건수와 손실 합계는 별도로 유지합니다.

회사 상세 차트에는 원 단위 눈금과 직전 및 구간 시작 대비 변동액·변동률을 표시합니다. 지정가 주문은 즉시 체결과 대기를 구분하고 실제 가격 변화로 상승·하락·보합을 집계합니다. 저장 경로 중복과 구형 저장의 10초 제한 문제를 수정하고 Windows 학습 주석을 보완했습니다.

## 조작

`h` 도움말, `l` 종목 목록, `d ID` 회사 상세, `p` 보유 자산, `o` 주문, `t` 거래 기록입니다. `b/s ID 수량`으로 시장가 주문, `lb/ls ID 수량 가격`으로 지정가 주문, `cancel 주문ID`로 미체결 주문을 취소합니다.

일반용은 `restart` 다음 `restart yes`로 새 게임을 시작하고 `restart no`로 취소합니다. `q`는 저장 후 종료입니다. 시연용은 `pause`, `resume`, `step`, `event crash`, `event boom`, `event delist ID`, `event fill 주문ID`, `reset`을 지원합니다.

## 저장과 기록

본 저장 1개와 복구 파일 2개를 고정 이름으로 덮어씁니다. 종료 중에는 시장이 진행되지 않습니다. 기존 `data/game_v4.sav` 위치를 이어 사용하고 형식 4와 5를 읽습니다. V3는 알림을 포함한 형식 5를 기록합니다. 파일명과 프로그램 버전은 별개의 식별입니다.

## 검증

Debug와 Release에서 각각 98,221개 검사와 실제 실행 검사를 통과했습니다. 실제 구형 저장 복원, 폐지 알림 유지와 확인, 큰 가격 차트, 지정가 결과, 다시하기를 확인했습니다. 시장은 200개 난수 시작값의 480회·4,800회 갱신 표본을 검사했습니다. 4,800회 비용 전 가상 지수 중간 수익률은 약 75.945%, 평균 폐지는 1.485건입니다. 비용과 정수 수량을 포함한 실제 플레이어 수익률은 전략에 따라 달라집니다.
